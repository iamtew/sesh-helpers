# Documentation

Sesh Helpers documentation — for mortal meat bags and the clankers who serve them.

The overlays and ABS backdrop apps are live static web apps. These docs describe the
contracts the code already implements; app-specific operator notes live beside each app.

## Conventions

- **`00x_` files** — numbered, ordered reading for agents.
- **Unnumbered files** — feature or domain specifications.
- **Implementation contracts** — verify claims against the code when behavior changes.
- **Operator notes** — document every persisted URL parameter and its default.

When adding a new doc or helper app, update this index so neither clankers nor meat
bags have to divine the repository layout.
